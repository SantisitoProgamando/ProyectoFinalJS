**Instrucciones criticas para la buena ejecucion del proyecto:**
1. Abrir la carpeta del proyecto en VSCode.
2. Tener instalada la extension "Live server"
3. Una vez instalada o ya instalada, hacer click derecho sobre el archivo "index.html" y seleccionar "Open with live server"
4. El proyecto se ejecutara en el navegador mediante un servidor local

----- Si no se hace con live server, el proyecto no funcionara correctamente, ya que se necesitan las funciones de un servidor para manejar el carrito de compras y las interacciones con los productos. -----
